<h2 align="center">🖥️ Sobre o projeto</h2>

<br>

O DevSorteio é uma aplicação web que permite sortear números aleatórios dentro de um intervalo definido pelo usuário.

Com uma interface simples e intuitiva, o projeto foi desenvolvido com foco na praticidade, responsividade e aplicação dos conceitos fundamentais do JavaScript.
